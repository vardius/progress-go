## What you get

<CardGrid>
	<Card title="One atomic add" icon="rocket">
		`Advance` adds to a counter and returns. It never draws and never allocates, so it fits in the tightest
		loop.
	</Card>
	<Card title="Workers share a bar" icon="puzzle">
		Call `Advance` from as many goroutines as you like. `Start` and `Stop` are safe from any of them too.
	</Card>
	<Card title="Calm on a terminal" icon="laptop">
		A timer redraws the bar in place ten times a second, however fast the work goes, so the terminal never
		floods and a slow job's times keep ticking.
	</Card>
	<Card title="Plain in logs" icon="document">
		Written to a file, a pipe or a buffer, the bar is one line at `Stop`, with no escape codes.
	</Card>
	<Card title="Exact at the edges" icon="approve-check">
		Integer maths for any `int64` count. The percentage stays within 0 and 100%, and a job stopped part way
		shows where it stopped.
	</Card>
	<Card title="Verbose without pauses" icon="information">
		The heap size comes from `runtime/metrics`, which doesn't stop the world, beside the time elapsed, the
		estimated total and the time remaining.
	</Card>
</CardGrid>

## Faster than the untagged version, with nothing to allocate

<div class="landing-lead">
	`Advance` no longer draws: it is one atomic add. A timer redraws the bar ten times a second, formatting it
	into a reused buffer and writing it in one call, and the verbose heap size no longer stops the world.
	With 16 goroutines at once, the time is wall time per call across all of them, so it measures throughput.
</div>

## Coming from the untagged version

<div class="landing-lead">
	The options and the bar on screen are as before. The calls return less, a total replaces start and max, and
	`Stop` now shows where a job stopped instead of filling the bar.
</div>

<div class="compare">

```go title="untagged"
bar := progress.New(0, n, progress.Options{})
_, _ = bar.Start()
for _, f := range files {
	process(f)
	_, _ = bar.Advance(1)
}
_, err := bar.Stop()
```

```go title="v1"
bar := progress.New(n, progress.Options{})
bar.Start()
for _, f := range files {
	process(f)
	bar.Advance(1)
}
err := bar.Stop()
```
